# Common-Data-Model
Common Data Model for BreastSCan, build with Common Data Model Builder

BreastSCan is a project funded by the European Commission, and aims to foster the development of AI models to improve the early diagnose of breast cancer in the context of screening programs.

This repository covers the Common Data Model for the BreastSCan project (https://cancerimage.eu/breastscan/), built using the Common Data Model Builder (https://cienciadedatosysalud.github.io/cdmb-web/), developed by the Data Science for Health Services and Policy Research Group (DSHSPR) in th Institute for Health Sciences in Aragon (https://cienciadedatosysalud.org/).

The Common Data Model has been jointly designed by the Institute for Health Sciences in Aragon and Hospital La Fe in Valencia.

This CDM covers the needed entities for:    
- women
- images related data
- pathological specimens
- surgical treatment
- neoadjuvant treatment
- follow up

The CDM includes the structure of the model, CSV files with sample synthetic data, and the needed scripts to test the validity of the selected data through the CDM Validator.
